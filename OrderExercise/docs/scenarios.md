Перед выполнением каждого сценария происходит следующее:
0. Программа запускается, создается объект "repository" с нужным типом, реализующим интерфейс IOrderRepository, и передается в OrderService

## Сценарий: Создание пустого заказа

1. Пользователь выбирает пункт "Создать заказ"
2. ConsoleController вызывает OrderService.CreateOrder()
3. OrderService создаёт объект класса Order и вызывает метод AddOrder() переданного объекта "repository", который добавляет заказ в список заказов

## Сценарий: Просмотр списка заказов

1. Пользователь выбирает пункт "Посмотреть список заказов"
2. ConsoleController вызывает OrderService.GetOrders()
3. OrderService вызывает метод GetOrders() переданного объекта "repository", который возвращает список заказов

## Сценарий: Поиск заказа по номеру

1. Пользователь выбирает пункт "Найти заказ по номеру"
2. ConsoleController собирает данные пользователя (Id заказа), валидирует и вызывает OrderService.GetOrderById(...)
3. OrderService вызывает метод FindOrder(...) переданного объекта "repository", который возвращает найденный заказ

## Сценарий: Удаление заказа по номеру

1. Пользователь выбирает пункт "Удалить заказ"
2. ConsoleController собирает данные пользователя (Id заказа), валидирует и вызывает OrderService.DeleteOrderById(...)
3. OrderService вызывает метод DeleteOrder(...) переданного объекта "repository", который удаляет найденный заказ из списка

## Сценарий: Добавление товара в заказ

1. Пользователь выбирает пункт "Добавить товар в заказ"
2. ConsoleController собирает данные пользователя (Id заказа, название товара, артикул товара, цена товара, кол-во товара), валидирует и вызывает OrderService.AddOrderItem(...)
3. OrderService создаёт объект класса Product, затем OrderItem и вызывает метод AddOrderItem(...) переданного объекта "repository", который добавляет товар с количеством в заказ

## Сценарий: Удаление товара из заказа

1. Пользователь выбирает пункт "Убрать товар из заказа"
2. ConsoleController собирает данные пользователя (Id заказа, артикул товара), валидирует и вызывает OrderService.DeleteItem(...)
3. OrderService вызывает метод DeleteItem(...) переданного объекта "repository", который удаляет товар со всем его количеством

## Сценарий: Изменение кол-ва товара в заказе

1. Пользователь выбирает пункт "Изменить кол-во товаров в заказе"
2. ConsoleController собирает данные пользователя (Id заказа, артикул товара, новое кол-во товара), валидирует и вызывает OrderService.UpdateOrderItem(...)
3. OrderService вызывает метод UpdateOrderItem(...) переданного объекта "repository", который устанавливает новое значение количества товара
