# OrderExercise — архитектура

## Слои

Program
- Точка входа
- Создаёт зависимости
- Передаёт управление контроллеру

Controller (ConsoleController)
- Принимает ввод пользователя
- Вызывает методы сервиса
- Выводит данные в консоль
- НЕ содержит бизнес-логики

Service (OrderService)
- Содержит бизнес-логику
- Создаёт и изменяет доменные объекты
- Работает с репозиториями
- Не знает про консоль

Repository
- Отвечает за хранение данных
- Не содержит бизнес-логики
- Возвращает доменные объекты

Domain
- Сущности (Order, OrderItem, Product)
- Сами управляют своим состоянием
- Ни о ком не знают
